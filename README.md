## Sobre

Engenheiro de software com trajetória sólida em **servidores de jogo**, **motores gráficos em C++** e **aplicações de tempo real** que precisam funcionar sob pressão — não só em demo.

Há mais de uma década construindo e mantendo ambientes multijogador persistentes: protocolos de rede, sincronização de estado, economias virtuais, salas e instâncias, anti-abuso básico e deploy em produção para operadores e empresas com requisitos fechados.

Trabalho onde **robustez importa**: memória previsível, concorrência bem definida, falhas contidas e código que aguenta refatoração anos depois.

> *Driven by Innovation. United by Vision.*

## Domínio técnico

| Área | Foco |
|------|------|
| **Servidor de jogo** | Autoridade de sessão, filas, persistência, escalonamento de instâncias |
| **Engine & runtime** | C/C++, SDL, loop de simulação, renderização 2D, assets e tooling |
| **Rede & protocolo** | Pacotes enxutos, estado consistente, reconexão, tolerância a latência |
| **Produção** | Linux, containers, monitoramento, entrega contínua para clientes privados |
| **Camada aplicada** | TypeScript, Go, Python — painéis, APIs e ferramentas em torno do core nativo |
